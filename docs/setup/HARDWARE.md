# Requisitos de hardware

## Desenvolvimento (Unreal Editor + Blender)

| Item | Mínimo | Recomendado |
|---|---|---|
| SO | Windows 10 64 bits 22H2 | Windows 11 64 bits |
| CPU | 6 núcleos / 12 threads | 8+ núcleos (compilação C++ e shaders) |
| RAM | 16 GB | 32 GB ou mais |
| GPU | DX12, Shader Model 6, 6 GB VRAM | 8 GB+ VRAM (RTX 3060/RX 6600 ou superior) |
| Disco | SSD com 150 GB livres | NVMe dedicado (E:) |

Confira os requisitos oficiais atualizados: https://dev.epicgames.com/documentation/unreal-engine/hardware-and-software-specifications-for-unreal-engine
